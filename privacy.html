隱私權政策 Privacy Policy

最後更新：2026-11-20

Body Decoded Studio 僅供「身體解碼」頻道經營者本人使用，不對外提供服務。

  • 本工具透過 Google OAuth 取得 YouTube Data API 權限，只用來上傳本頻道自己的影片、設定縮圖與影片資訊、排定發布時間，以及讀取本頻道影片的狀態與統計數據。
  • 授權令牌只儲存在頻道經營者自己的電腦上，不會傳送給任何第三方。
  • 本工具不收集、不儲存、不分享任何其他使用者或觀眾的個人資料。
  • 可隨時在 Google 帳戶的「第三方存取權」頁面撤銷授權。

Body Decoded Studio is used solely by the operator of the "身體解碼" YouTube channel. It uses YouTube Data API access only to upload the channel's own videos, set thumbnails and metadata, schedule publishing, and read the channel's own video status and statistics. OAuth tokens are stored only on the operator's own computer and are never shared. No personal data of any other user or viewer is collected, stored or shared. Access can be revoked at any time from the Google Account third-party access page.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
